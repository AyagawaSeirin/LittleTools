# LittleTools

一个基于 Vue 3 与 Ant Design Vue 的纯前端浏览器工具箱。它可以直接部署到 GitHub Pages，主要计算都在本地完成，并适配桌面、平板与手机屏幕。

## 已实现工具

- 随机密码生成：字符集、排除字符、长度、批量生成、强度估算与会话历史
- 日期计算器：日期差、完整年月日、工作日、日期向前 / 向后推算
- 随机端口生成：自定义合法端口范围、唯一结果与常见端口速查
- 随机 IP 地址：IPv4 / IPv6、CIDR、起止范围、唯一结果与文本下载
- IP 范围计算器：IPv4 / IPv6 网络范围、掩码、可用范围、PTR 等信息
- 时间戳转换：秒 / 毫秒自动识别、本地时间、UTC、ISO 8601 双向转换
- IP 信息查询：进入页面自动查询访客公网 IP，也可查询指定地址的大致位置、网络组织和时区
- 文本编码转换：Base64、URL、HTML 实体、Unicode、Hex、二进制
- 在线文本编辑器：大编辑区、行号、撤销/重做、普通与正则搜索、匹配高亮、逐项/全部替换、复制全文
- 正则表达式测试与编辑：JavaScript / PCRE2 双引擎、实时高亮、分组详情、语法解释、替换/提取、测试集、本地模式库、收藏与分享
- JSON 格式化与树形查看：格式化、压缩、语法错误定位和可展开/收起的结构浏览
- 多国地址生成器：按需加载 27 个国家和地区的数据包，生成关联一致的虚构地址与测试资料
- Nmap 命令生成器：通过目标、扫描方式、端口、探测、NSE、时序和输出选项生成命令
- iperf3 命令生成器：覆盖服务端、客户端、TCP、UDP、SCTP、负载、性能、输出和认证参数
- tcpdump 命令生成器：覆盖实时捕获、pcap 读取、BPF 过滤、输出格式、文件保存和轮转参数

全站支持白天 / 黑夜模式、用户自定义主题色和设置持久化。除在线文本编辑器外，各工具会在浏览器中独立记住输入参数与选项，下次访问时自动恢复；生成结果和查询结果不会缓存。

在线文本编辑器的正文、搜索词、替换内容和撤销历史仅存在于当前页面内存中，不上传，也不写入 localStorage、sessionStorage、IndexedDB、URL 或离线缓存；刷新、关闭页面或切换到其他工具后清空。只有主动点击“复制全文”才会写入系统剪贴板。正则模式直接输入表达式（无需 `/.../`），支持 `$1`、`$2`、`$&` 分组替换，以及 `\n`、`\t` 换行和制表符。

## 正则表达式工作台

入口为 `/#/regex-tester`，首页和侧栏均可访问。参考 [RegExr](https://regexr.com/) 的工作流程，沿用 LittleTools 的中文界面、主题和响应式布局。

- 表达式编辑与测试文本编辑均使用 CodeMirror，支持撤销/重做、语法高亮、悬停提示；匹配支持导航、零宽标记、捕获分组详情与 JavaScript 分组定位。
- JavaScript 使用浏览器原生 RegExp；PHP / PCRE2 使用本地 WebAssembly，支持递归、原子分组、条件分支、占有量词和 `\K`。切换引擎会移除不兼容的修饰符，并为 PCRE 默认启用 Unicode。
- 替换与提取提供模板预览、复制、下载和应用到文本；支持完整匹配、编号/命名分组、前后文引用与换行/制表符。应用替换后可撤销。
- 测试集支持完整匹配、包含匹配、不应匹配与指定匹配次数，每项独立执行；提供分类速查、语法参考与 14 个内置示例。
- 草稿自动本地保存。模式可命名、添加说明/作者/标签、保存或另存为、搜索、收藏、删除，以及通过 JSON 导入/导出。刷新后继续编辑已保存模式不会产生重复记录。
- 分享链接将文档编码在 URL fragment 中，可选择包含测试文本和测试集；没有账号、在线社区或跨用户评分。任何拿到完整链接的人都能查看其中内容。较大的文档请导出 JSON。

正则在独立 Worker 中执行，180 ms 防抖，单次超过 3 秒会终止；最多展示 5,000 处匹配，超过上限时禁止生成不完整的替换/提取输出。文本最多 100 万 UTF-16 单元，表达式最多 2 万，测试集最多 200 项且总文本不超过 100 万，输出最多 200 万字符，模式库最多保存 100 项。本地存储不足时会提示导出备份。

PCRE 当前封装不提供捕获分组的起止位置，也不能处理含原始 NUL 的测试文本；非 ASCII 文本需要启用 `u`，以避免 UTF-8 字节匹配与浏览器字符位置混淆。PCRE 的解释按语法片段展示，复杂条件、递归和局部选项以实际引擎结果为准。工具的输出模板兼容 JavaScript 语法和部分 PCRE 写法，不完全等同于 PHP 的 `preg_replace` 替换语法。

新增专项单元测试在 `src/__tests__/regex.test.ts`，实际浏览器检查记录见 [正则工具检查记录](docs/regex-tester.md)。

## 离线与缓存

生产构建会生成版本化的 Service Worker，并在首次在线访问时预缓存首页、样式和全部工具页面资源。多国地址工具的数据按国家分包，第一次选择某个国家时才下载并缓存；已经使用过的国家之后可以离线生成。除 IP 信息查询和地址工具的可选 IP 预选外，主要计算都在浏览器本地完成。

页面顶部的 **更新缓存** 按钮会主动检查网站新版本、重新缓存核心工具资源并刷新页面。多国地址数据包保持按需加载，网站版本更新后会在再次选择对应国家时获取新数据。发现新版本时按钮会显示提示点；离线时页面会显示“离线模式”，并暂时禁用缓存更新。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

运行测试与生产构建：

```bash
npm test
npm run build
npm run preview
```

全站响应式与浏览器交互复测方式见 [前端检查记录](docs/frontend-audit.md)。脚本支持外部已有的 Playwright 安装，不增加项目依赖。

文本编辑器专项检查使用 `node scripts/check-text-editor.mjs`，覆盖搜索替换、撤销、长文本、内容不落盘与离线编辑；同样支持 `PLAYWRIGHT_MODULE`、`QA_BROWSER`、`QA_WIDTHS`、`QA_THEMES` 等配置。

## 部署到 GitHub Pages

项目已包含 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)。将代码推送到 `main` 分支后：

1. 在 GitHub 仓库打开 **Settings → Pages**。
2. 将 **Build and deployment → Source** 设为 **GitHub Actions**。
3. 等待 `Deploy to GitHub Pages` 工作流完成。

站点使用 hash 路由和相对资源路径，因此可部署在用户主页或任意仓库子路径下，不需要额外配置 `base`。

当前自定义域名由 [`public/CNAME`](public/CNAME) 写入 Vite 构建产物。GitHub Pages 的发布源必须选择 **GitHub Actions**，不能直接从仓库根目录发布源码。

## 数据与隐私

密码、日期、端口、随机 IP、CIDR、时间戳、文本编码和虚构地址生成均在浏览器本地处理。进入“IP 信息查询”页面后会自动请求 [IP.SB](https://ip.sb/api/) 获取访客公网 IP 与大致网络信息；服务不可用时会尝试 [ipwho.is](https://ipwho.is/)，指定 IP 还可由 [monip.lws.fr](https://monip.lws.fr/sv/api) 备用查询。多国地址工具只有在用户主动使用 IP 预选时才会调用 IP.SB 或 ipwho.is。待查询 IP 会发送给实际使用的服务，本项目本身不存储查询内容。

随机密码、端口与 IP 使用浏览器的 `crypto.getRandomValues()`，不使用 `Math.random()`。
