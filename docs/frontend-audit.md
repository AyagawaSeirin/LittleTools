# 前端与响应式检查记录

检查日期：2026-09-07。范围为首页与全部 13 个工具页，使用本地 `kill-ai-slop` 技能扫描、人工核对源码、浏览器截图复查及交互验证。

## 已修正

- 首页改用直接的工具说明，移除重复口号、装饰徽章、编号和彩色图标底块；链接内容使用自然布局，解决 320px 下说明文字与操作链接重叠。
- 顶栏改用实色，移除卡片和彩色标志阴影；保留现有主题配色，统一标题图标、字体和层级。
- 修正组件库覆盖移动端样式的问题：顶栏名称被挤出、长分段选项被截断、滑块端点超出字段边界。
- 根据卡片实际宽度调整表单列数；命令预览在内容空间不足时移到表单上方，短屏取消吸顶。
- 日期、时间戳、CIDR、JSON 和地址页分别调整网格、结果换行、操作栏和说明字号。
- 日期时间弹层在窄屏及横屏短屏内固定定位、限制高度并允许滚动；必填日期禁用清空，避免后续计算读取空值。
- JSON 树修正数组索引和对象键显示、展开箭头重复旋转，以及深色选择器编译后错误作用到根元素的问题。
- 自定义主题色的强调文字与主按钮前景色自适应明暗；深色滑块和密码强度文字提高可读性。
- 补充移动菜单关闭按钮、复制按钮标签、主题色选中状态和键盘焦点。

## 复测方式

没有新增项目依赖。浏览器脚本使用环境中已有的 Playwright，可通过 `PLAYWRIGHT_MODULE` 指向外部安装的 `index.mjs`。

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

在另一个终端运行：

```sh
node scripts/check-responsive.mjs
node scripts/check-interactions.mjs
node scripts/check-popups.mjs
```

可配置 `QA_BASE_URL`、`QA_OUTPUT_DIR`、`QA_BROWSER`（`chromium` / `firefox` / `webkit`）、`QA_BROWSER_EXECUTABLE`。前两个脚本支持逗号分隔的 `QA_WIDTHS` 和 `QA_THEMES`。默认输出到系统临时目录；输出包含 JSON 检查记录与页面/弹层截图，不进入 Git。

`kill-ai-slop` 在相同应用范围内的候选项从 31 处降至 14 处。剩余项目经人工确认保留：编码测试中的 emoji、国家识别图形、真实缓存更新提示点、主题色选择圆点，以及 JSON、IP、端口、时间戳和编码文本所需的等宽字体。
