## 范围

依据 [RegExr](https://regexr.com/) 公开功能核对：表达式与文本编辑、JavaScript 和 PHP/PCRE 引擎、修饰符、实时高亮与悬停详情、捕获分组、Replace/List/Details/Explain、测试集、速查与参考、模式保存及分享。按需求确认采用纯前端方案，用本地模式库、内置示例、收藏、JSON 交换和 URL 分享实现模式管理；不提供账号或在线社区。

新增依赖：`@eslint-community/regexpp`（ECMAScript 结构解析）、`pcre2-wasm`（PCRE2 10.47，WebAssembly 内嵌）。引擎代码位于独立 Worker，PCRE 模块按需初始化；构建产物均进入现有 Service Worker 缓存清单。

## 使用边界

- PCRE 封装仅暴露捕获文本，捕获分组位置按钮不启用；整体匹配位置可用。
- PCRE 测试文本中的原始 NUL 明确报错，非 ASCII 文本需要 u；没有用 JavaScript 模拟不支持的 PCRE 语法。
- PCRE 解释为语法片段级说明；局部修饰符、递归和条件的语义以真实引擎运行结果为准。
- 超过匹配上限时详情只展示前 5,000 项，替换/提取输出被阻止并明确提示。
- 保存/收藏依赖当前浏览器的本地存储；分享内容在链接中，未建立公共模式服务。
